# Gene Expression Filtering (R)

Compares `control` vs `treated` expression for 6 genes, computes fold change,
and classifies each gene as `upregulated`, `stable`, or `downregulated`.

## Files
- `gene_analysis.R` — the script
- `results.txt` — output generated by the script (fold change, matrix, classification)

## How to run

1. Make sure R is installed (`Rscript --version` to check).
2. From a terminal, in the folder with the script:

   ```bash
   Rscript gene_analysis.R
   ```

3. The script prints all steps to the console **and** writes the same
   summary to `results.txt` in the same folder.

## What the script does
- Builds `control` and `treated` as named vectors (named by `gene_names`)
- Computes `fold_change <- treated / control` (vector arithmetic, no loop)
- Subsets genes where `fold_change > 1.5`
- Combines `control` and `treated` into one matrix (`genes x conditions`) with `dimnames`
- Computes per-gene averages with `rowMeans()`
- Classifies every gene in one shot with a nested `ifelse()`:
  - `fold_change > 1.2` → `"upregulated"`
  - `fold_change < 0.8` → `"downregulated"`
  - otherwise → `"stable"`
- Converts that result into a `factor` with fixed levels
  (`upregulated`, `stable`, `downregulated`) instead of leaving it as plain text
- Saves everything to `results.txt` using `sink()`
